ด้วยความขี้เกียจล้วนๆ เวลาช่วยแฟนแพ็คของส่งลูกค้าต้องมานั่งกรองข้อมูลลูกค้าทีละเคส 
เลยทำระบบเล็กๆไว้ใช้เอง
วันนี้มีโอกาสเลยเอามาแจกให้ลองใช้ครับ 
เผื่อมีใครขี้เกียจเหมือนกัน🤣
**ระบบพิมพ์ใบปะหน้าพัสดุ (A4 แบ่ง 3 ส่วน)**

ใช้งานได้ที่: https://tiw-thanapol.github.io/label-print/
---
🎯 จุดประสงค์
1. ช่วยให้การพิมพ์ชื่อและที่อยู่ลูกค้าสะดวกขึ้น ตั้งแต่ 1 เคส ไปจนถึงหลายเคส
   โดยไม่ต้องจัดฟอร์มใน MS Word หรือ Excel
2. ใช้งานง่าย รองรับทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์
   (สามารถพิมพ์ผ่าน Printer Wi-Fi ได้)
---
👤 เหมาะกับใคร
✅ คนที่เริ่มต้นขายของออนไลน์
✅ พ่อค้าแม่ค้าที่ต้องการลดขั้นตอน แต่ยังไม่อยากลงทุนกับระบบใหญ่
  เช่น เครื่องพิมพ์สติ๊กเกอร์ หรือระบบจัดการออเดอร์เต็มรูปแบบ
---
⚙️ วิธีการใช้งาน
1. ใช้งานผ่าน PC / Notebook / โทรศัพท์ / Tablet ได้ทันที
2. ไม่ต้องติดตั้งแอปใด ๆ
3. Copy + Paste ข้อมูลลูกค้า (ชื่อ + ที่อยู่ + เบอร์โทร + หมายเหตุ) ได้หลายรายการ
4. ระบบจะจัดแยกลูกค้าแต่ละราย เป็นใบปะหน้าอัตโนมัติ (A4 แบ่ง 3 ช่อง)
5. ไม่มีการบันทึกข้อมูล และไม่เชื่อมต่อระบบภายนอก
6. ใช้เพื่อจัดรูปแบบและสั่งพิมพ์เท่านั้น
---
 ⚠️ ข้อสังเกต
🟡รองรับข้อมูลตัวอักษรทั่วไป
🟡หากข้อมูลมีรูปแบบเฉพาะ เช่น
 ที่อยู่ไม่เป็นมาตรฐานหรือ มีชื่อซ้ำในรายการเดียว
อาจทำให้ระบบแยกข้อมูลผิดพลาดได้
🟡แนะนำให้ตรวจสอบข้อมูลก่อนพิมพ์ทุกครั้ง
🟡 หากพบข้อมูลผิดพลาด ควรแยกแก้ไขทีละเคส
---
❗ ข้อสำคัญ
1. ตรวจสอบว่าอุปกรณ์เชื่อมต่อ Printer เรียบร้อยแล้ว
2. หากมีหลายลูกค้า ต้องคั่นข้อมูลด้วยเครื่องหมาย
   **—— (ขีดยาว)** ทุกครั้ง
---
🚨 คำเตือน
1.ระบบนี้ช่วยอำนวยความสะดวกในการจัดรูปแบบเท่านั้น
2.ผู้ใช้งานต้องตรวจสอบข้อมูลก่อนพิมพ์ทุกครั้ง
3.ทางระบบไม่รับผิดชอบต่อความผิดพลาดที่เกิดขึ้น
