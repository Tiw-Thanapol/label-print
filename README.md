"ระบบปรินท์ใบปะหน้าพัสดุ ใช้กับกระดาษขนาดA4 แบ่ง3ส่วน"
https://tiw-thanapol.github.io/label-print/

**การใช้งาน**: สามารถใช้งานผ่านPC,Notebook โทรศัพท์มือถือ Tablet ได้ โดยไม่ต้องโหลดแอปพลิเคชั่นใดๆ 
โดยการทำงานดังนี้ สามารถcopy+paste ข้อมูลลูกค้า (ชื่อ+ที่อยู่+เบอร์โทร+Note) โดยระบบจะคัดแยกลูกค้าแต่ละรายให้เป็นใบปะหน้าในแผ่นA4แบ่ง3ส่วน
ระบบไม่มีการบันทึกข้อมูลใดๆ ใช้เพื่อปรินท์อย่างเดียว
ระบบนี้สามารถใช้งานได้ทั่วไป แต่หากมีข้อมูลที่เฉพาะเจาะจงบางอย่างหรือข้อมูลนอกเหนือจากข้อมูลปกติระบบอาจจะประมวลผลผิดพลาด ดังนั้นต้องตรวจสอบด้วยตัวเองเสมอ เพื่อป้องกันความผิดพลาดในงานใช้งาน

**ข้อสำคัญ**: ต้องแน่ใจว่าอุปกรณ์ที่ใช้งานเชื่อมต่อกับเครื่องปรินท์เรียบร้อยแล้ว

**คำเตือน**: ระบบอาจจะมีข้อผิดพลาด ดังนั้นกรุณาตรวจสอบข้อมูลด้วยตัวเองทุกครั้งก่อนพิมพ์เสมอ
และไม่รับผิดชอบต่อความผิดพลาดใดๆ
